# packages/codegraph/src/ast-graph/languages/python

How a `.py` or `.pyi` file is read. Read [Python](../../../../../../docs/vocabulary/codegraph/languages/python.md) before changing anything here. The rules of [ast-graph/AGENTS.md](../../AGENTS.md) and of [packages/codegraph/AGENTS.md](../../../../AGENTS.md) hold here too.

## Rules

- **Python binds names, it does not declare them.** `ast-graph/languages/python/` holds `readPythonSyntax` in `index.ts`. `bindings.ts` reads every place a name is bound (a `def`, a `class`, a parameter, an assignment target, a loop, `with`, `except`, `:=`, a `match` capture, a type parameter, an import) and keeps the first one in each scope as the declaration; a later binding of that name in that scope is a use. A scope is the body of a function or lambda, a comprehension, or the file. There is no block scope, `global` and `nonlocal` move a binding to the scope they name, and what a class body binds is neither a variable nor a use, because a method cannot see it. Every import of a name is kept when its first binding is an import, so `import shop.tax` and `import shop.pricing` both count.
- **A Python file gives its statements.** `statements.ts` reads them for the traced lines of a node: a `def`, a `class` and an assignment are a `declaration`, a decorated one from its first decorator; an `if` and a `match` are a `conditional`, a `for` and a `while` a `loop`, a `try` a `try`, a `raise` a `throw`, `break` and `continue` a `jump`, an import an `import` and a type alias a `type`. The arms are the body of an `if`, of an `elif` and of an `else`, the right side of `and` and of `or`, each `case`, the body of a loop, and the `try`, `except` and `finally` of a `try`. A `with` is an `expression` that holds the statements of its body. A Python file gives no syntax sites.
- **A Python import of a name may be a module.** `from shop import pricing` has the imported name `*` when the file it resolved to is the module `pricing`, and `pricing` when the file is the package that defines it.
