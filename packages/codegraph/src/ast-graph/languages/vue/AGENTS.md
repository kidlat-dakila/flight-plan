# packages/codegraph/src/ast-graph/languages/vue

How a `.vue` file is read. Read [Vue](../../../../../../docs/vocabulary/codegraph/languages/vue.md) before changing anything here. The rules of [ast-graph/AGENTS.md](../../AGENTS.md) and of [packages/codegraph/AGENTS.md](../../../../AGENTS.md) hold here too.

## Rules

- **A Vue file is three languages.** `ast-graph/languages/vue/` holds `VueASTGraphFile`, which takes the tree of the whole file parsed with the `html` grammar (`tree-sitter-html`). `sfc.ts` finds the script blocks and the template in it. `script.ts` parses each script block with the TypeScript grammar its `lang` names and reads it with the TypeScript extractions. `template.ts` parses every expression of the template (an interpolation, a bound attribute, a handler, the two sides of a `v-for`, the properties of a slot) as a snippet of TypeScript. `snippet.ts` moves what a snippet found to its lines and columns in the file.
- **A Vue component is the default export.** A `<script setup>` block and the template are each a root encapsulation named `default`, and a file that does not export a default declares the variable `default`, so an importer's default import leads to them. The top level of a setup script is seen by the template, the top level of a script without setup is not. A `v-for` variable and a slot property are seen inside their element only. A capitalised tag, a tag with dashes and the object of a member tag are uses of the component's name, and `v-focus` is a use of `vFocus`.
- **A Vue file gives the journey what a JSX file gives it.** `extractSyntaxSites` gives an `attribute` site for every `@event` and `v-on` handler and every bound attribute of the template, an `element` site for every tag, a `markup` site for the template and a `page` site for a component named by a route record. `extractStatements` gives the statements of the script blocks, with the elements of the template as `markup` statements. Nothing in `journey-flow-diagram/` asks whether a file is a Vue file.
- **Vue says with its own syntax what JSX says with attributes.** An emitted event is a prop: `@save` on a component is followed into that component, to where `emit("save")` or `$emit("save")` runs. `provide(key, value)` is a `Provider` value and `inject(key)` its reader. The top level of a `<script setup>` block and the template are the render body, and a function declared at that top level is a function declared in the component. The branches of a `v-if`, `v-else-if`, `v-else` chain at the root of the template are the returns of the component.
- **A Vue component is a `ui` node named after its file.** `Cart.vue` is `Cart`. A handler node is named `<component>.<handler>`, or `<component>.<event>` for an expression written in place, and an entry of `events` is `<element>.<event>`.
