The first time you open Flight Plan, every page takes you to setup. It has four steps, and each one is saved as you go, so you can stop and pick up where you left off.

1. [Agent integration](/docs/setup/agent-integration/): how Flight Plan works with your coding agent.
2. [Git integration](/docs/setup/git-integration/): how Flight Plan reaches your pull requests.
3. [Prompt configuration](/docs/setup/prompt-configuration/): how the agent writes your reviews.
4. [Repositories](/docs/setup/repositories/): the repositories and team members Flight Plan follows.

The rail on the left marks each step as **Saved**, **Current step** or **Not reached**. A step opens only after every step before it is saved. **Back** returns to the previous step, and **Save and continue** saves the step you are on. The last step ends with **Finish setup**. If something is missing, the button stays disabled and says what to do first.

## Changing it later

The settings menu in the header links to each section of **Settings**, and switches between dark and light mode.

| Settings section | What it holds |
|---|---|
| **Agent integration** | Your agents and how Flight Plan works with them. Saving installs Flight Plan into each agent again. |
| **Git integration** | Your connections to GitHub, GitLab, Bitbucket and local git. |
| **Prompt configurations** | The presets, your own configurations, and which one is the default. See [Preset profiles and customizing](/docs/presets/). |
| **Repositories** | The repositories you added and the team members you follow in each one. |

Agent integration and Git integration use the same forms as setup, with a **Save** button.
