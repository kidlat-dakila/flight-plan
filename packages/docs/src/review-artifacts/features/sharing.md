---
title: Sharing
description: Attach a review to the pull request description or publish it as a Claude artifact.
---

**Share** gives a review to people who don't run Flight Plan.

## Attach to the pull request description

**Attach** uploads the review artifact as a file to the pull request and links it from the description. **Open the description** shows where it went. This needs a forge.

## Publish as a Claude artifact

**Publish** asks your agent to publish a read-only copy as a private Claude artifact. It's one page with the whole review and the code it shows, which anyone you share it with can read without Flight Plan or the repository. When the agent is done, **Open the artifact** appears under Share.

Publishing again updates the same artifact, so its link stays the same.

## Bringing a published review into Flight Plan

A published copy can only be read. Its header has **Download to Flight Plan**. That link opens **Download a Flight Plan** in your own Flight Plan, where your agent fetches the review from the artifact and stores it for the same repository and pull request. If you already have a Flight Plan for it, **Replace and download** overwrites yours.

On a Flight Plan you wrote yourself, Share appears once it is complete.
