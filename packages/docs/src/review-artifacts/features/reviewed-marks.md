---
title: Reviewed marks
description: Mark waypoints and files as reviewed, so you only see what's left to read.
---

Reviewed marks keep track of what you've read. Mark a waypoint or a file as reviewed and it fades and then hides, so the walkthrough shows only what's left.

- **Reviewed** on a waypoint marks that waypoint, and so does **Mark as reviewed** (S) in the Review Navigator.
- **File reviewed** on a file marks the whole file. A file whose waypoints are all reviewed counts as reviewed too.
- Tick **Reviewed** in the walkthrough's **Filter** to bring the hidden ones back.

A mark lasts until the content changes. When the pull request moves and a waypoint's code is different, it comes back unmarked, so you read it again.

The marks are stored on your machine. They aren't part of the review artifact and aren't sent to the forge. The waypoints inside the Trace Diagram's side panel carry the same toggles.
