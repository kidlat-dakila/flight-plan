The Context comes first in each segment. It says why the change exists, in words you read before any code.

![The Context of a segment, with its overview and its implementation list](../../../media/context-light.webp)

## What it holds

With the Standard configuration, the Context has three parts:

1. **An opening paragraph** of up to five sentences, with no code names, paths or links in it.
2. **Overview:** what happens when the change runs, written as **When** … **then** … scenarios.
3. **Implementation:** what changed and where, grouped by place, with one item per change and a link to the code for each.

The links in it are code links. Hover one to see the code it points at, and click it to open that code in the walkthrough.

## On your own Flight Plan

On your own Flight Plan, **Edit** opens the Context in an editor with formatting buttons. **Code link** inserts a link to code: pick a file, select the lines (click a line number, then shift-click another) and name the link.
