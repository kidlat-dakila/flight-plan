The segment's title: a very short text of what the segment's `context` is
about, a few words long. One string, with no code link and no full stop.

A segment arrives with no title. Write it with `update-document { segmentId, title }`,
after the context it sums up, and a finished artifact has one on every segment.

The review page shows it as the segment's heading when a change is split into
several segments, and the section rail lists the segment under it.
