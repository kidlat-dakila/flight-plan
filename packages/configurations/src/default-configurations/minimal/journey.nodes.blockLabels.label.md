What this row of the node is for, as a reader of the product: "Promo code
shopper typed", "Sends order to API". Read the node's code first: label says
what the block holds or does, not what it is called.

- **Argument or state**: what the value holds: `Cart lines`, not `items`.
- **Hook**: what it gives the node: `Mutation that applies promo code`.
- **Effect**: what it does, when: `Clears form after save`.
- **Call**: what is asked of the code it calls: `Saves renamed user`.
- **Step**: what the step does: `Returns error for empty title`. Condition: what
  is checked. Step standing for several statements: what they do together.
