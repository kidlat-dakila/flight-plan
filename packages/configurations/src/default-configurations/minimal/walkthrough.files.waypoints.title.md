**What was done, to what.** "Modified file reader to return reason for binary
content", "Returns null for path outside root". Not a bare noun: "The file
reader" names which code, not why the reader is shown it.

**Past tense**: Added, Modified, Removed. Never the identifier alone.

**One title, one thing.** Arrow, "and" or three clauses: several waypoints
crammed into one.

**Child's title: smaller change than its parent's.** Same shape, same tense,
every level.
