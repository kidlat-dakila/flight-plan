### Trace

Steps that prove the finding, in the order code runs.

**First step: the trigger.** Action and what makes it fire: parameter, state,
condition. "Reader selects a sentence", not "selection happens". `POST /orders`
with `quantity: 0`, not `POST /orders`. User action: no link.

**Every later step: a debugger step**, linked to its place in the code. Proof
only: no impact, no evidence, no proposal. No trace on a `nit` or a `question`.
