### Solution

Every `bug`, `risk`, `nit` carries a solution. A `question` carries none.

The lines as they should be, whole, with the indentation they have in the file.
Never shortened: code is not prose. Solution replaces every line the finding's
waypoint covers: a line left out is a line the fix deletes.

Fix needs more than these lines: write the part that belongs to these lines.
Name the other lines that must change in the reading, with `code:` links.
