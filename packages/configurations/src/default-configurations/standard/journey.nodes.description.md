Carry the half the label cannot. First sentence: *how* the node does what the label says. The rest: *why* it is in the path — the constraint it keeps true, the alternative rejected, what breaks without it. The card already shows the label and the identifier, so carry on from the label's sentence rather than restating it. A changed node leads with `**The change.** …`; a context node says it is unchanged and what it contributes.
