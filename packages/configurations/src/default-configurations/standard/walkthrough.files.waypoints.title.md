**Say what was done, and to what** — "Modified the file reader to return a reason
for binary content", "Returns null for a path outside the root". Not a bare noun
like "The file reader" or "The error path": a noun names which code this is about but not why
the reader is shown it, which is the one thing a title is for.

**Past tense** — Added, Modified, Removed. Never the identifier on its own.

**One title, one thing.** An arrow, an "and", or three clauses means several
waypoints crammed into one.

**A child's title is a smaller change than its parent's**, not a different kind
of thing: same shape, same tense, at every level.
