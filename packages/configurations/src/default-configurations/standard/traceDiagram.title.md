Name the flow the diagram shows, the way the user would name it. Six words at most, ending in "flow diagram".

- **One flow.** Name the action that sets it off: `Submit order flow diagram`.
- **Two flows.** Name both, joined with "and", in the order the diagram draws them: `Render orders and create order flow diagram`.
- **Three flows or more.** Naming each would not fit. Name the page, the component, the job or the route they all start from: `View Order page flow diagram`.
- **A path nobody clicks.** Name what starts it, such as the request, the schedule or the other system: `Order webhook flow diagram`.

Use the words of the screen, not the names of the code: `Submit order`, not `handleSubmit()`. Start with a capital letter and leave out the full stop.

| The diagram | Its title |
|---|---|
| A form whose change is only its submit | Submit order flow diagram |
| A page that renders the orders and creates one | Render orders and create order flow diagram |
| A page that loads, filters, edits and deletes orders | View Order page flow diagram |
