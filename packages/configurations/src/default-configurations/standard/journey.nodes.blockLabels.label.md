Say what this row of the node is for, as a reader of the product would: "The promo code the shopper typed", "Sends the order to the API". Read the code of the node first, so the label says what the block holds or does, not what it is called.

- **An argument or a state.** Say what the value holds: `The lines of the cart`, not `items`.
- **A hook.** Say what it gives the node: `The mutation that applies a promo code`.
- **An effect.** Say what it does and when: `Clears the form after a save`.
- **A step.** Say what the step does: `Refuses an empty title`. For a condition, say what is checked.

Leave the name of the code out: the row shows it under your label. Keep the same shape and tense on every block label of one node.
