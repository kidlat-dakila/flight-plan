### Then

Write what a person or system can observe once the situation holds — one sentence. Say
the observable result, not the mechanism: "the error message names both
out-of-stock lines". Link the code the result comes from where there is code to name.

Say "nothing changes" when a reader would reasonably expect a change and there
is none; that line stops a reviewer hunting for a regression that is not there.
A "nothing changes" then carries no link.
