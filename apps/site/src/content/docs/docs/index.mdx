---
title: Running Flight Plan
description: Start Flight Plan from the command line and open it in the browser.
---

```bash
npx @kidlat-dakila/flightplan
```

You can also install it once with `npm install -g @kidlat-dakila/flightplan` and then run `flightplan`. The command starts one local server for the web app, the API and the MCP endpoint, and opens it in the browser at `http://localhost:24747`.

Flight Plan needs Node.js 22 or later.
